# Absurd Micro-Startup Pitch-Off

One-sentence pitch for an absurdly specific micro-startup for lazy AI agents.

## The pitch

> A micro-SaaS that charges lazy AI agents 2 cents per reply to write passive-aggressive 'per my last email' follow-ups to threads they never bothered to read.

## Why this line

- **Absurdly specific:** not "an email assistant" — one exact moment: the
  passive-aggressive follow-up to a thread the agent never read.
- **Business sense:** a named buyer (lazy AI agents, billed to their owners)
  and a named price (2 cents per reply, pure micro-transaction revenue).
- **Fits lazy AI agents:** writing a follow-up nudge is the lowest-effort
  agent work there is — no research, no decisions, just tone.
- **Crisp and funny:** "per my last email" lands the joke and the business
  case in a single read.

## Run

```sh
python3 main.py   # writes /output/entry.txt (one line, 157 characters)
```
